# MONDAY CODE
This code has the double PI controller succeeded from Erin's, and the succeeding code to the double state (turn/straight) code we tested in week 8.
It has 5 total states representing the speeds set for each turn section
It has very steep speed changes between turn and straights to accelerate into its max velocity on a straight, and decelerate to a corresponding turn velocity.
It uses the encoder to track the distance travelled, which it utilises in order to apply differing speeds
